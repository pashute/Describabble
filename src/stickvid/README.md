# stickvid v0.1.7

Web player for Describabble stick figure animations.

## Usage

1. Start the server: `npm start`
2. Open http://localhost:3003 in your browser
3. Click **Load .vid File** to select a manifest file (e.g., `surveyGuy.vid`)
4. Use the controls to play: **<<** (first), **-<** (previous), **[]** (stop), **||** (pause), **|>** (play), **>+** (next), **>>** (last)
5. Scrub the timeline or drag the locator to seek
6. View current and total time in the readouts below
